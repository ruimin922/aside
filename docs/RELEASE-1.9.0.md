# 旁白 Aside 1.9.0

2026-09-20 · 观看记录界面与交互更新

## 本次更新

- 完整首页使用日轮与山形曲线作为整页背景，前景是可透视的玻璃记录库；浅色模式增强通透度。
- 统一明暗主题、提示信息、细线手绘指针与悬浮球；产品图标改为暖沙色。
- 按视频展开记录，加入轻量纸张抽出效果；帮助、分享与键盘焦点样式统一。
- 悬浮记录库与快速记录支持拖动和调整窗口大小，移除预设界面缩放设置。
- 快速记录仅保留时间、字幕、保存；快捷键悬停可见。恢复草稿等成功提示 3 秒后自动消失，保存失败保持可见。
- Agentation 仅用于开发预览，安装包不含标注工具、示例数据或开发服务器。

## 安装与更新

1. 下载 `aside-v1.9.0.zip` 并解压，找到直接包含 `manifest.json` 的文件夹。
2. 在 Chrome 地址栏打开 `chrome://extensions`，开启右上角「开发者模式」。
3. 首次安装：点击「加载已解压的扩展程序」，选择该文件夹。
4. 已使用开发者模式安装：将新包内容覆盖到原来的插件文件夹，再点击该扩展的「重新加载」。不要先删除扩展，以免清掉本地记录。
5. 刷新已打开的视频页和旁白页面。Chrome 扩展详情中的版本应为 **1.9.0**。

本项目维护者可直接加载仓库内的 `movie-notes-extension/`，以后改完代码只需重新加载扩展并刷新视频页，无需反复下载包。已有商店版时，先在原版导出重要记录；商店安装与开发者加载是不同的更新路径，不要把卸载重装当作升级。

## 体验路径

打开 YouTube 或 B 站视频，点击右侧悬浮球或按 `Alt/Option + N` → 写下想法 → 保存 → 点击浏览器工具栏中的旁白图标查看记录库。记录库右上角 ↗ 打开完整首页，可看到山川背景；悬浮面板透出当前网页。

macOS 下快捷键若被占用，可到 `chrome://extensions/shortcuts` 查看和修改。预览中的示例记录不会迁移到真实插件。
