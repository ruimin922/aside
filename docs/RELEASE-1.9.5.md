# 旁白 Aside 1.9.5

2026-09-20 · 播放器记录体验与界面更新

本次汇总 1.9.1 后的本地迭代，包含播放器入口、快捷记录、样式隔离及 Agentation 设计批注调整。

## 观看与记录

- 用播放器底栏的旁白入口替代常驻悬浮球；支持 YouTube、哔哩哔哩、爱奇艺、优酷、芒果 TV、腾讯视频的控制栏结构，未识别时提供视频底部入口。
- 快速记录跟随入口按钮定位，优先避让可识别字幕，并为画面内自带字幕预留底部空间。极小窗口或特殊字幕位置可手动拖动调整。
- Option / Alt + N 打开或收起快速记录；Esc 留给播放器。草稿静默保存、恢复，存储失败时仍提示。
- 移除图钉与跨次固定位置，移除记录库顶栏关闭按钮；Option / Alt + L 或扩展工具栏按钮可收起记录库。
- 快速记录与底栏按钮使用 Shadow DOM 隔离，避免视频网站样式把线条图标覆盖成色块。

## 界面与编辑

- 默认深色，保留手动浅色选择；调整首页玻璃层、悬浮窗口边距与窄窗口布局。
- 「旁白」标题增加轻微悬停倾斜、平滑回正和键盘聚焦反馈；系统开启减少动态效果时关闭该动效。
- 简化时间点、时间段和分类输入，保留自定义分类草稿；快捷键信息收敛到悬停提示。
- 本地 Agentation 预览继续支持隔离后的按钮标注，并加入视频网站样式干扰验证入口。

## 更新

开发者模式安装：将版本包内容覆盖到原插件文件夹，在 `chrome://extensions` 重新加载旁白，再刷新视频页面。直接加载仓库 `movie-notes-extension/` 的用户只需重新加载和刷新，无需卸载。

GitHub 更新不会自动更新本地已安装插件，也不会自动发布至 Chrome 插件市场。

## 验证范围

67 项自动测试覆盖数据、草稿、后台消息、Notion、数据库与播放器定位；本地预览验证深浅主题、窄窗口、字幕避让、快捷键、样式冲突和标题动效。安装包检查脚本语法、资源依赖、版本及 ZIP 完整性。

尚未对本版本进行所有真实视频网站的完整扩展验收；Google 登录、线上云同步、真实账号导出不由预览检查代替。
