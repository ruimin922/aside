# 旁白 Aside 1.9.2

2026-09-20 · 播放器底栏入口与样式隔离

## 改动

- 快速记录和播放器入口使用独立的 Shadow DOM 样式，防止视频网站的按钮、SVG、字体规则将图钉、关闭图标和旁白入口覆盖成色块。保留 Agentation 开发预览中的元素标注。
- 观看入口移到播放器底栏，记录窗默认从视频底部打开；支持拖动并记住位置，图钉可恢复到底部。适配六个网站的底栏结构，无法识别时回退到视频底部入口。
- Option / Alt + N 打开或收起记录，Esc 留给播放器退出全屏。切换窗口保留草稿，默认深色并保留用户主动选择的浅色主题。
- 收录本轮首页、玻璃界面、标签与时间点输入、窄窗口布局的设计调整。

## 更新方法

1. 将 `aside-v1.9.2.zip` 解压后的内容覆盖到原先加载的插件文件夹，保持文件夹位置不变。
2. 在 `chrome://extensions` 找到旁白，点击「重新加载」，确认版本为 **1.9.2**。
3. 刷新已经打开的视频网页，再用底栏入口或 Option / Alt + N 测试。旧网页不会自动换成新脚本。

如果直接加载的是本仓库的 `movie-notes-extension/` 文件夹，只需完成第 2、3 步。保留原扩展即可，无需卸载。包内不包含开发预览或 Agentation。

## 验证范围

- 63 项自动回归测试通过，覆盖笔记、草稿、后台快捷键路由、Notion、数据库和播放器位置计算。
- 本地浏览器使用强制覆盖按钮尺寸、背景、SVG 填充与描边的干扰样式，复现旧实现的色块问题；隔离后图标、按钮、输入框保持预期样式。
- 本地检查深浅主题、390px 窄窗口、六种播放器底栏结构及备用入口；验证固定/取消固定、快捷键开关、草稿恢复、焦点循环、返回记录库、全屏挂载与 Esc 保留记录窗，以及 Agentation 选取图钉和底栏入口。
- 安装包检查脚本语法、资源引用、版本一致性与 ZIP 完整性。尚未在用户截图对应的线上播放器安装验证，不能据此视为所有真实网站已通过验收。

开发时可打开 `/__agentation/scene.html?hostStyles=1` 重复样式冲突检查。
