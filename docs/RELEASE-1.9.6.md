# 旁白 Aside 1.9.6

2026-09-20 · 恢复电影图案与透明底图标

修正 1.9.5 中误换的产品图案：恢复手绘电影对白框、播放三角和引号，保留图案内的米白填色，外围改用 PNG 透明通道。

同步扩展工具栏、页面图标、移动版图标和商店图标源文件，并更新图标缓存版本。

## 更新

下载 `aside-v1.9.6.zip`，将内容覆盖到原插件文件夹，在 `chrome://extensions` 重新加载旁白，再刷新视频页面。直接加载仓库 `movie-notes-extension/` 的用户只需重新加载和刷新，无需卸载。

GitHub 更新不会自动更新本地插件，也不会自动发布到 Chrome 插件市场。

## 验证范围

核对图标 PNG 尺寸及透明通道，并通过安装包的脚本语法、资源依赖、版本和 ZIP 完整性检查。此次只修正品牌资源；真实浏览器扩展安装后的显示仍以重新加载后的结果为准。
