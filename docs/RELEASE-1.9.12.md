# 旁白 1.9.12

搜索结果直接展示命中的笔记片段与标签，并高亮关键词。点击片段可定位到对应记录，时间按钮沿用视频跳转能力；返回记录库保留搜索词。仅标题或视频标签匹配时只展示该视频入口，不混入无关笔记。支持清除搜索、无结果提示和方向键导航。

未登录状态明确显示「本地使用」，修复原先误显示等待同步的问题。离线网络失败提示「离线待同步」，保留登录过期、云端结构异常等独立原因；本地保存提示与云端同步状态分开。

新建记录、空状态、帮助和整体想法等文案面向访谈、课程、视频播客及电影。包含 1.9.11 的原版播放器图标和跨页面共用窗口工具。

## 安装

- 本地体验：解压 `dist/aside-v1.9.12.zip`，加载解压后的目录；已有源码安装可在 Chrome 扩展管理页重新加载，再刷新视频页面。不要先卸载已有插件。
- 商店更新：向原条目上传 `dist/aside-v1.9.12-chrome-web-store.zip`。此包不含 manifest 的 key 字段。
