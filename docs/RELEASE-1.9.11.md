# 旁白 1.9.11

播放器底栏入口改用与产品一致的原版透明图标，保留深紫外框和浅紫内芯，显示尺寸为 28 像素。图标继续置于隔离样式的 Shadow DOM 内，避免视频网站覆盖其样式。

置顶、使用帮助和主题切换在记录库首页、视频详情、新建记录和设置页共用同一组控件，切页保留置顶状态，编辑记录时可打开帮助和切换主题。置顶仅显示于视频页的悬浮记录库；独立标签页无需固定。详情页的记录、导出、删除另排一行，适配窄窗口。

## 安装

- 本地体验：解压 `dist/aside-v1.9.11.zip`，在 Chrome 扩展管理页加载解压后的目录；如使用项目目录安装则点击重新加载。更新后刷新视频页面。
- 商店更新：上传 `dist/aside-v1.9.11-chrome-web-store.zip` 到原旁白条目。商店包不含 manifest 的 key 字段。

## 验证

- 本地示例视频中验证原版图标加载和快速记录开关。
- 详情、新建、编辑、设置页的帮助与主题切换，悬浮记录库的置顶状态跨页保留。
- 深浅主题及 336 像素悬浮窗口预览。
- 本次浏览器检查使用开发预览，不代表真实视频网站扩展端到端验证。
