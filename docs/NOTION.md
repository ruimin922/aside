# 把旁白记录导出到 Notion

## 首次连接

请在安装的 Chrome 插件中操作。本地 Agentation 页面只预览交互，不接入真实 Notion。

1. 打开 [Notion 连接管理](https://www.notion.so/profile/integrations)，新建内部连接（Internal），名称可填「旁白」。选择你要使用的工作区；若不能创建，需要工作区所有者协助。
2. 在 Capabilities 中开启 **Read content（读取内容）** 和 **Insert content（插入内容）**。从 Configuration 复制连接密钥，粘贴到旁白「设置 → 连接 Notion → 连接密钥」。
3. 在同一工作区新建普通页面「旁白记录」。在该页面右上角 **··· → 连接 / Connections → 添加连接** 中选中刚才创建的「旁白」，然后复制页面链接，粘贴到旁白。
4. 点击 **验证并连接**。旁白先读取目标，再创建一个「旁白连接测试」子页面。只有实际创建成功，才保存这组配置并显示「已验证写入」。测试页不含你的笔记，可自行删除。
5. 在设置中导出全部记录，或在某个视频的详情页导出。每个视频生成一个子页面。导出结果中可直接打开生成的页面。

## 以前测试成功，为什么还是导出失败？

1.9.0 及更早版本的测试只读取页面，且不会保存测试中的输入；导出使用最后一次保存的配置。因此，测试成功既不证明有写入权限，也不证明导出使用的是刚才测试的那组设置。

1.9.1 合并了验证和保存。既有配置会保留，建议点击一次「验证并连接」重新确认写入。上述是已确认的旧流程问题，具体工作区失败原因仍以新版错误详情为准。

| 新提示 | 处理方式 |
| --- | --- |
| 密钥无效或失效 | 到连接管理复制当前密钥并重新验证。不要填写登录密码。 |
| Notion 拒绝写入 | 检查 Insert content 权限、目标页面的连接授权；若提示工作区额度，先处理额度限制。 |
| 找不到已授权的页面 | 确认连接和页面在同一工作区、已添加连接、页面未删除。使用普通页面链接，暂不支持数据库作为目标。 |
| 内容未被接受 | 展开「错误详情」，反馈错误文字；不用发送密钥。 |
| 没有返回写入结果 | 先打开目标页面，检查是否已生成记录，再决定是否重试。 |
| 页面已创建，但内容未写完 | 点击结果中的页面链接检查已有内容。整段重新导出会创建另一页。 |

密钥仅保存在本浏览器当前旁白账号的本地设置中，不随笔记云同步，也不写入 GitHub。清除连接不会删除 Notion 已有页面。

## 实现与验证边界

请求保留 HTTP 状态和错误代码；对明确的限流做有限重试，对结果不确定的写入不自动重发。长记录同时按块数、富文本数组长度和 UTF-8 请求大小分批。测试使用受控 API 响应，不访问个人 Notion 工作区。

参考：[Notion 内容权限](https://developers.notion.com/reference/capabilities)、[页面授权](https://developers.notion.com/guides/get-started/authorization)、[错误代码](https://developers.notion.com/reference/status-codes)、[请求限制](https://developers.notion.com/reference/request-limits)。
